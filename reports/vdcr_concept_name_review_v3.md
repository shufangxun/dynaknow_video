# VDCR v1 Concept Name Review v3

Date: 2026-06-06

## 审核原则

这次只审“视频动态专有名字”本身是否适合作为 VDCR 答案标签，不审具体视频素材。

VDCR 合格答案不是“视频里发生了什么动作/事件”，而是“这个连续动力学过程在专家知识体系里对应哪个专有机制、技术、策略或动态图样”。

因此，一个概念名要进入 v1 主池，应同时满足：

1. 有稳定命名：论文、教材、行业/学科训练体系中有相对固定叫法。
2. 依赖时序：单张图不能稳定唯一判别，必须看过程阶段、轨迹、周期、前沿、反馈或形变。
3. 不是泛动作：不能只是“跑、跳、喷、崩、流、摆、转、捕食、闭合”。
4. 有机制边界：名称背后能解释为动力学、反应动力学、生理机制、生态策略或地球过程。
5. 可做近邻负例：可以和同域相近概念混淆，而不是靠场景、物体或标题猜中。

## 总体结论

当前 245 个概念中，方向总体正确，但 v1 主池应继续收紧。最适合做主干的是：

- 物理：流体不稳定性、界面/液滴动力学、波动振动、刚体/颗粒动力学。
- 化学材料：流变响应、振荡反应、自组织沉淀、晶体/枝晶生长、相分离动力学。
- 生物：植物响应、细胞显微动态、微生物群体动态、少量有正式阶段结构的动物生态策略。
- 地球环境：风暴生成/旋转/出流、火山碎屑流、熔岩前缘、坡面/河流/风沙过程。

人体专项运动和球类战术可以保留为 stress slice，但不应承担 v1 主体。它们是“专业动态动作概念”，不是普通动作识别；但学术叙事上仍弱于自然科学机制。

## 对人体和体育类的处理

人体专项运动不是不能做，但必须把它定义为“有正式规则体系和阶段判据的专有动态动作概念”，并严格限制比例。

建议 v1 中最多占 5-8%，且只保留以下相对强的：

- Figure skating jumps: Axel Jump, Salchow Jump, Toe Loop Jump。理由是必须看起跳刃、旋转方向、落冰阶段。
- Gymnastics vault/release: Yurchenko Vault, Tsukahara Vault, Kovacs Release。理由是有固定技术序列。
- Judo throws: Ippon Seoi Nage, Uchi Mata, Osoto Gari, Tomoe Nage。理由是投技结构依赖进身、破势、发力和落地阶段。
- Water/snow board skills: Eskimo Roll / Kayak Roll, Eggbeater Kick, Carving Turn。理由是比普通动作更有机制边界。

篮球战术类建议暂放 extension，不进入 v1 主体。Spain Action、Elevator Screen、Hammer Action 等确实有多人时序结构，但素材版权、广播字幕、战术上下文泄漏风险较高，且学术上容易被质疑为 sport play recognition。
